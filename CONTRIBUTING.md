# Contributing to Roots of Life


## Branching
- main: stable code
- dev: development work
- Feature branches: feat/<name>
- Fix branches: fix/<issue>


## Workflow
1. Fork or clone the repository
2. Create a new branch: git checkout -b feat/add-ui-enhancements
3. Commit your work using COMMIT_TEMPLATE.txt
4. Push your branch
5. Open a Pull Request


## Code Style
- Follow Kotlin best practices
- Follow Android Jetpack guidelines


## Issues
- Use tags: bug, enhancement, documentation, help wanted
